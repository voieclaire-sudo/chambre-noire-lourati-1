La pièce sombre

Une chambre sombre pour chacune des 24 leçons. Trouve les mots cachés dans les cases avec la lampe torche, ou allume la lumière pour t'aider. Le bouton « + Mots » permet d'ajouter tes propres mots à chaque leçon.

Manche Trouvés Erreurs Points

Ajoute un mot dans la bonne catégorie. Les nouveaux mots (contour doré) apparaissent dès la prochaine manche. Le × retire un mot. Pour un mot dans une phrase, mets le mot visé entre crochets : الوَلَدُ [مُجْتَهِدٌ] (et [___] pour un blanc).

Réglages
